# better-effect documentation

This is the Fumadocs documentation application for `better-effect`.

From the repository root:

```bash
bun run docs:dev
```

Or run the app directly from this workspace:

```bash
bun run dev
```

Documentation pages live in [`content/docs`](./content/docs). The app uses the
Next.js App Router, Fumadocs MDX, and the Fumadocs UI layout/search components.
