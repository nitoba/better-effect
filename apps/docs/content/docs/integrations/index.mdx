Integrations are adapters around the core boundaries. Choose the surface where
your application starts, then keep Services and Layers in your application code
so the framework remains replaceable.

## A useful composition

Use a web or framework adapter at the request boundary, call a Service from the
handler, and provide the database or auth implementation through the same Layer
that serves the application. Add [MQ](/docs/mq) when work needs durable retry,
and add the [Outbox](/docs/outbox) when a successful transaction must publish
after commit.
