Integrations keep their host library's boundary intact. They provide Services or Layers that your
composition root owns; they do not create a second application runtime or move business logic into
a container.

## Pick the boundary you own

Use [Web and framework adapters](./web) for request lifetimes, [Schema](./schema) for explicit
decoding, and [Backends](./backends) when you need to understand resolver ownership. For queues,
start with [MQ](../mq) before selecting a database adapter.
