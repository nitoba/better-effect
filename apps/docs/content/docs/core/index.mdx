for success and failure, and add only the boundaries that make application
architecture easier to see.

## When to combine them

Start with `Service` and `Effect` for application behavior. Add a `Layer` when
the behavior needs a concrete implementation, a `Runtime` when the application
needs a long-lived owner, and `Scope` when resources must close at a boundary.
The [integration guides](/docs/integrations) show how those same boundaries fit
inside requests and external libraries.
