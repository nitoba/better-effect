`better-effect-mq` is a storage-neutral package for durable jobs and
Layer-first Workers. A **queue** is a namespace, a **Job** is an immutable
producer/handler identity, and a **JobStore** is the persistence seam. A Worker
runs handlers over one existing `better-effect` Runtime; it does not create a
second Runtime or choose a database.

Storage adapters are separate packages. The current adapter family includes
PostgreSQL, Redis/Valkey, MongoDB, SQLite and MySQL; each preserves the base
protocol and documents its extension migrations, client ownership and
transaction boundaries in its package README. The storage-neutral
[`better-effect-mq-outbox`](https://github.com/nitoba/better-effect/tree/main/packages/better-effect-mq-outbox)
package provides prepared outbox records, routing and a Layer-owned publisher.

The public package surface is exported from `better-effect-mq`; runner-neutral
helpers are under `better-effect-mq/testing`. The package uses only
`better-effect` and `better-result` as its core foundations and contains no
SQL, Redis or other driver. Adapter authors can use the [technical
reference](./reference) for persistence invariants and migration details.
